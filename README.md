# EczSearch (Flutter)

Türkiye’de il/ilçe seçerek **nöbetçi eczaneleri** görüntüleyen, telefondan **ara** ve **haritada aç** (Google / Apple / Yandex) özelliklerine sahip mobil uygulama.

## Özellikler
- 81 il + ilçe seçimi (offline veri paketi ile)
- Nöbetçi eczaneleri CollectAPI üzerinden getirme
- **Ara** (tel:) ve **Haritada Gör** (Google/Apple/Yandex) yönlendirmeleri
- “**Bana En Yakın Eczane**” (konum izni + Haversine ile en yakın koordinat)

flutter pub get
flutter run
